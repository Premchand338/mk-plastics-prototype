Pehle yeh padh lo

  • Har test se pehle Zero reset → Haan, zero karo. Masters (rate list, users, pirai spec, dhaga register) bache rehte hain.
  • User badalna: Logout → ← Doosra number → naya mobile → Aage badho → PIN.
  • Staff (Vinod / Salman) pehle Shift Shuru, phir Entry Daalo.
  • Moulding ki entry: menu Approval. Coating ki entry: menu Coating → Final approval.
  • Jo number "Kya dikhna chahiye" mein hain, wahi aane chahiye (jaise ₹6,136). Thoda bhi alag ho toh Note mein likho.
  • Kuch dropdown chip ki tarah dikhte hain: naam par tap karo.
  • Laptop par chalao (side menu dikhta hai). Phone par menu neeche "Aur" mein hota hai.
