Shabd aur hisaab

ShabdMatlab
BunchHamara standard: 1 bunch = 1,200 moti (Rate list → Pirai spec se badal sakte ho).
PacketPacking × 1,200 moti. 8mm: 4 bunch = 4,800 moti.
Ladi · Guchha · FrameKarigar ladi pirota hai; kai ladi = 1 guchha; 2 guchha = 1 frame. Moti / frame = guchha × ladi × moti / ladi (P2 register). 8mm Semi: 2 × 18 × 50 = 1,800.
Exact frame / packetPacket ka moti ÷ frame ka moti. 8mm: 4,800 ÷ 1,800 = 2.667.
AllowanceTooti ladi ke liye owner ka frame / packet (8mm = 2.8). Task target = packet × allowance.
Dhaga g/kg1 kg pirai (dhaage ke saath) mein kitne gram dhaga (P1 register). Dhaga = kul wazan × g/kg.
CutJo moti pir nahi saki (hole band) → waste, usi grade mein.
Reject bunch(Frames × moti/frame − packets × moti/packet) ÷ 1,200 → Waste "Coating reject".
Work dateKis din ka kaam: entry agle din hoti hai, isliye pehle se kal.

Poora flow ek nazar mein

Raw material (line)→Moulding task + entry→Approval→Karigar ko bhejo (spec)→Wapas lo (grade, dhaga, cut)→Coating mein bhejo
Order slip→Coating task (packet → frame)→Roz ki entry (work date)→Approval→Dispatch→Bill (abhi / baad mein)

Stock sirf owner ke approval par badalta hai. Bikri ka stock dispatch par ghatta hai, bill par nahi. Pearl ka maal Pearl mein, Metalizing ka Metalizing mein apne aap.

1

Order slip

Version v14.1Kaun karega: Owner (admin)

Order ab owner ki slip book jaisa: ek slip number, ek item ke kai rang, har rang ke packet.

Step by step

  1. Orders → Naya order dabao. Slip number apne aap aata hai (book ka agla, jaise 224).
  2. Tareekh, Party, Transport (kahan se → kahan tak; party ka shehar apne aap) bharo.
  3. Item chuno (size + Semi / Super …), Unit (Pearl / Metalizing), Grade, Coating.
  4. Rang chuno aur packet daalo. Doosra rang: "Aur rang". Doosra size: "Aur item".
  5. Rate rate list se aata hai; deal alag ho toh badlo. Sign mein order lene wale ka naam.
  6. Slip save karo. App batata hai kya stock se jaayega aur kis rang ka coating task dena hai.

Dhyan do

  • Agla slip number: Orders page par "Agla slip #…" se badal sakte ho. Ek number do baar nahi chalega.
  • Pehla slip pehle: list mein sabse purana slip upar (1, 2, 3). Taiyaar stock bhi pehle purane slip ko milta hai.
  • Party-wise tab: har party, har rang: Order / Bane / Baaki. Pura hone par Ready to dispatch.
  • Order kholo → Slip dekho: book jaisa kaagaz.
1b

Pehle dispatch, phir bill

Version v14.2Kaun karega: Sirf owner

Owner ka jawab (Q11): maal pehle jaata hai, bill saath mein ya baad mein. Bill par dispatch ki tareekh.

Step by step

  1. Order kholo → Dispatch karo (pehle "Bill banao" tha).
  2. Har rang ke packet (taiyaar stock tak), gaadi number, dispatch ki tareekh, maal ki photo.
  3. Bill kab? → Abhi bill banao: rate dekho (slip se bhara), GST / Kachcha chuno. Ya Bill baad mein.
  4. Save: stock usi waqt minus. Abhi bill chuna toh invoice turant: WhatsApp · PDF download.
  5. Bill baad mein: Orders → Bill banana baaki → Bill banao → final rate → invoice.

Dhyan do

  • Invoice ki tareekh = dispatch ki tareekh. Bill kis din bana, woh alag save hota hai ("Bill bana …").
  • Har dispatch ka alag bill; do order kabhi ek bill mein nahi.
  • Bill setting (Orders page): pehle se kaunsa chuna ho, bill kitne din mein (2), credit limit par warning ya rokna.
  • PDF: browser ka print → "Save as PDF"; file ka naam bill number. WhatsApp mein message taiyaar, PDF haath se jodo.
2

Karigar ko pirai ke liye bhejna

Version v14.3Kaun karega: Owner

Karigar ko bata ke bhejna ki guchha kaise banana hai. 1 bunch = 1,200 moti; karigar frame / guchha mein deta hai.

Step by step

  1. Karigar → Karigar ko bhejo: karigar, moulded maal, kitna kg.
  2. Pirai spec maal se apne aap chunta hai (P2 register). Galat ho toh dropdown se badlo.
  3. Box "Guchha kaise banana hai": jaise 8mm Semi: 18 ladi = 1 guchha · 2 guchha = 1 frame · 50 moti / ladi = 1,800 moti / frame. Saath mein andaazan frame.
  4. Bhejo + challan banao: challan par bhi yahi spec.

Dhyan do

  • Spec ki list: Rate list → Pirai spec (31 lines, sab badal sakte ho). 6 Munga par "confirm baaki".
  • 1 bunch = 1,200 moti: Pirai spec ke upar button se badal sakte ho.
  • Rate list mein naye item: 6 B.H.L. aur 6 Semi Flat (rate baaki).
3 + 4

Karigar se wapas lena + Dhaga stock

Version v14.4Kaun karega: Owner (receiver: jaise Salman)

Return entry bilkul karigar ki slip jaisi; dhaga apne aap alag; cut waste mein; dhaga ka stock.

Step by step

  1. Karigar page → job par Wapas lo.
  2. Upar: Karigar · Item · Challan. Tareekh aur Maal kisne liya.
  3. Grade 1st / 2nd / 3rd (zaroori: bina grade save nahi).
  4. Kitne frame aaye + khule guchha → app moti aur bunch nikaalta hai.
  5. Kul wazan (dhaage ke saath), Dhaga type, gram / kg (register P1 se), Cut.
  6. Neeche hisaab dekho: dhaga kitna, maal kitna, dhaga stock kitna bacha, cut kis waste mein → Threaded maal aaya.

Dhyan do

  • Dhaga = kul wazan × g/kg. P3 slip: 40.400 kg × 70 g = 2.828 kg dhaga, maal 37.572 kg.
  • Dhaga type pehli baar chuno, "Is item ke liye yaad rakho": agli baar apne aap.
  • Stock → Dhaga: Dhaga aaya, Ginti, Type / reorder. Reorder se kam → bell.
  • Cut → raw material ke type ka waste; Waste page par grade ke hisaab se bhi.
6

Coating task: packet se frame

Version v14.5Kaun karega: Owner

Owner packet dete hain, frame app nikaalta hai: packet = packing × 1,200 moti, frame = P2 spec, owner ka allowance.

Step by step

  1. Tasks → Coating task (ya order se "Coating task do").
  2. Machine (P1 / P2 / MZ1), lot, item, grade, rang, coating.
  3. Kitne packet chahiye daalo → Target (frames) apne aap.
  4. Box "Is item ka hisaab": 1 packet = 4,800 moti · 1 frame = 1,800 moti · exact 2.667 · allowance 2.8 → 100 packet = 280 frame.
  5. Task do: card par "280 frame ka target · 100 packet × 2.8".

Dhyan do

  • Allowance (tooti ladi ke liye): Rate list → Badlo → Allowance. Abhi sirf 8mm Semi = 2.8; baaki par exact.
  • Exact frame / packet (P2) rate list mein "P2" ke saath, read-only (spec badlo toh badlega).
  • 3MM Semi ka 1 frame = 6,000 moti = 5 bunch (pehle andaaza 10 tha).
7

Roz ki production entry

Version v14.6Kaun karega: Operator (Salman / P2 / Hamidur), approval owner

Aaj ke bane packet kal pack hote hain: entry agle din, work date ke saath. Reject apne aap.

Step by step

  1. Operator login → Entry. Upar work date (pehle se kal).
  2. Task chuno (progress dikhta hai: pehle + aaj = kul, baaki).
  3. Frames use hue aur Kitne packet bane.
  4. Hisaab: (frames × moti/frame − packets × moti/packet) ÷ 1,200 = reject bunch → Waste "Coating reject".
  5. Owner Approval → OK: stock = packet × packing.

Dhyan do

  • Packet khaali chhoda toh purana tareeka (pack hue frame / reject frame) chalta hai.
  • Target se 1–2 frame upar-neeche theek; zyada par warning.
  • Tasks page neeche: Operator ki entry · work date (owner ka tab).
5

Line routing + coating task ke box

Version v14.7Kaun karega: Owner

Pearl ka maal Pearl unit mein, Metal ka Metal mein. Owner ke task format ke box (Q6 ka intezaar).

Step by step

  1. Moulding task mein pehle Line chuno: usi line ka raw material dikhta hai.
  2. Wahi line aage chalti hai: moulded stock → karigar → threaded lot → coating.
  3. Coating task mein machine ke neeche: "Pearl line · …" / "Metalizing line · …". Lot sirf usi line ke.
  4. Task ke box: owner apne box jode (Number / Likhne ka / Tick). Naye task aur card par dikhte hain.

Dhyan do

  • Owner ka message (Q6) aate hi wahi box jod do, code nahi badlega.
  • Metal coating ki requirement owner baad mein batayega.
